# Built-in Agent Runner

By default, 摆烂仙君 uses the built-in Agent Runner as the default executor. You don't need to configure anything to use 摆烂仙君's powerful built-in Agent Runner.

![image](https://files.astrbot.app/docs/source/images/astrbot-agent-runner/image.png)

With the built-in Agent Runner, you can use 摆烂仙君's [MCP Server](/use/mcp), [Knowledge Base](/use/knowledge-base), [Web Search](/use/websearch), and persona features.
