# 摆烂仙君 Star

Starting from version `3.4.0`, 摆烂仙君 renamed plugins to `Star`. 摆烂仙君 is a highly modular project, and plugins leverage this modularity to implement various functionalities.

Use `/plugin` to view all plugins. You can also manage installed plugins in the admin panel.

If you want to develop your own plugin, see [摆烂仙君 Plugin Development Guide](/en/dev/star/plugin-new).
