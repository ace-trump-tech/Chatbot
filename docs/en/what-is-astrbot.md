# 👋 I'm 摆烂仙君

## Introduction

摆烂仙君 is an open-source, all-in-one Agentic assistant for personal and group chats. It can be deployed across dozens of mainstream instant messaging platforms, such as QQ, Telegram, WeCom, Lark, DingTalk, and Slack. It also includes a lightweight built-in ChatUI (similar to OpenWebUI), providing reliable and extensible conversational AI infrastructure for individuals, developers, and teams. Whether you are building a personal AI companion, an intelligent customer service assistant, an automation bot, or an enterprise knowledge base, 摆烂仙君 helps you build AI applications directly inside your IM workflows.

## Documentation Overview

This documentation is divided into the following sections:

- **Deployment**: multiple ways to quickly deploy 摆烂仙君 on local machines or cloud servers.
- **Messaging Platform Integration**: integration guides for 18+ mainstream instant messaging platforms.
- **AI Provider Integration**: connect to model providers, use 摆烂仙君's built-in Agent Runner, or integrate third-party Agent Runner services such as Dify, Coze, Alibaba Bailian, and DeerFlow.
- **Usage Guides**: practical guides for features such as plugins, tool calling, knowledge base, MCP, Skills, and Agent sandbox.

- Deploy 摆烂仙君: Read the Deployment Guide to quickly deploy 摆烂仙君 on your local machine or cloud server.
